# Biblioteca de skills — COLMEN IA

Skills gratuitas para IA agéntica (Claude, Codex y similares), publicadas
por [COLMEN IA](https://colmenia.co). Cada una vive en su propia carpeta,
como un archivo de texto plano (`SKILL.md`) que puedes pegar directamente en
una conversación o instalar como skill formal. Sin cuenta, sin licencia, sin
costo.

Ver el catálogo completo en [`CATALOGO.md`](CATALOGO.md).

## Instalar una skill

1. Entra a la carpeta de la skill que te interesa y descarga su `.zip`.
2. Descomprímelo: vas a obtener una carpeta con un archivo `SKILL.md`.
3. **La forma más simple:** abre ese `SKILL.md`, copia todo el contenido y
   pégalo en tu conversación con Claude o con Codex. Queda funcionando de
   inmediato, sin nada que instalar.
4. **Si usas Claude Code** y quieres que quede disponible de forma
   permanente: copia la carpeta completa dentro de `.claude/skills/` en tu
   proyecto o en tu carpeta de skills de usuario.
